이별 위험도 진단 앱 기획안
1. 앱 개요
앱명: LoveCheck (러브체크) 또는 관계온도계
타겟: 20-40대 연인 관계에 있는 사용자
핵심가치: 관계의 객관적 진단을 통한 예방적 관리
2. 주요 기능
2.1 진단 시스템

일일 체크: 간단한 5문항 일상 진단 (30초 소요)
주간 진단: 심화 분석 15문항 (3분 소요)
월간 종합진단: 전문적 심리 분석 30문항 (10분 소요)

2.2 진단 영역

소통 품질 (대화 빈도, 깊이, 갈등 해결)
감정적 친밀감 (애정 표현, 공감대, 신뢰)
미래 비전 공유 (목표 일치도, 가치관)
일상 만족도 (데이트, 루틴, 개인시간 존중)

2.3 결과 제공

위험도 점수: 0-100점 스케일
상세 분석 리포트: 영역별 점수와 개선점
맞춤 조언: AI 기반 관계 개선 팁
트렌드 분석: 시간별 관계 변화 그래프

3. 수익화 전략
3.1 프리미엄 구독 (월 4,900원)

무제한 진단 (무료: 월 3회 제한)
상세 분석 리포트
커플 동시 진단 기능
전문가 상담 연결 서비스

3.2 광고 수익

관계 개선 관련 서적/강의 광고
데이트 앱, 웨딩업체 제휴 광고

3.3 제휴 서비스

심리 상담 센터 연결 수수료
관계 개선 프로그램 판매

4. 기술 구현 (React Native)
4.1 핵심 기술 스택
현재 프로젝트 세팅된 기술 기반 개발 

AI: art_test폴더 > backend > src > config > constants.ts 참조
4.2 주요 화면 구성
온보딩 & 커플 등록
일일/주간/월간 진단 화면
결과 대시보드
히스토리 & 트렌드 분석
조언 & 팁 피드

5. 차별화 포인트
5.1 과학적 접근

심리학 기반 검증된 진단 문항
데이터 기반 객관적 분석

5.2 예방적 관리

문제 발생 전 조기 진단
단계별 맞춤 솔루션 제공

5.3 한국 문화 특화

한국 연인 문화에 맞춘 문항 설계
나이, 교제 기간별 맞춤 기준

6. 마케팅 전략
6.1 초기 론칭

인스타그램/틱톡 바이럴 마케팅
"우리 관계 점수는?" 챌린지 이벤트
연인 대상 무료 체험 이벤트

6.2 성장 전략

심리 전문가와 콘텐츠 협업
유명 커플 인플루언서 협찬
관련 유튜브 채널 제휴

7. 개발 우선순위
1단계 (MVP)

기본 진단 시스템
결과 분석 화면
사용자 등록/로그인

2단계

커플 연동 기능
히스토리 관리
푸시 알림

3단계

AI 맞춤 조언
프리미엄 기능
전문가 연결
